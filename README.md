# Furniro - E-Commerce Interior & Furniture Web Application

Furniro is a modern, responsive full-stack e-commerce application designed for browsing, comparing, and purchasing premium furniture and home interior products.

### Key Features
* **Interactive Product Catalog:** Dynamic product grid featuring filtering, sorting, price tags, and hover overlay actions (Add to Cart, Compare, Like).
* **Product Comparison Matrix:** Interactive comparison tool that lets users compare technical specifications, dimensions, and materials side-by-side.
* **Shopping Cart & Slide-Over Drawer:** Real-time persistent cart management with quantity controls, subtotal calculations, and item removal.
* **Interactive Reviews & Ratings:** Star-rating system and customer review submission section for verified product feedback.
* **Responsive Layout & Visual Feedback:** Mobile-optimized UI built with smooth animations, custom image fallback state handling, and vector icon integration.

### Tech Stack
* **Frontend:** React.js, React Router DOM, Tailwind CSS, Framer Motion, Lucide React
* **State Management:** React Context API (`CartContext`)
* **Build Tool:** Vite
* **Deployment:** Vercel / Netlify
